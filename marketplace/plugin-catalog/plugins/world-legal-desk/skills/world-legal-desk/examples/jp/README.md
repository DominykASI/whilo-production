# Japan (`jp`)

Stub for the folder convention in `../../README.md`. Not corpus text, not a citation.

- Corpus: the Japanese statutes as legalize-dev publishes them (`github.com/legalize-dev`).
- Version: filled in with the corpus's own date when the folder is populated.
- Licence: the corpus's terms, recorded here before a quote leaves the folder.
- Coverage: the Civil Code to start.

Article numbers in this folder keep their Japanese form (`第709条`) in the heading, as the corpus
writes them, rather than being translated to `Art. 709`.
