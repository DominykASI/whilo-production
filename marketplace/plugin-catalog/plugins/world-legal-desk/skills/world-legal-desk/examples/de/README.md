# Germany (`de`)

Stub for the folder convention in `../../README.md`. It is not corpus text and not a citation.

- Corpus: the German statutes as legalize-dev publishes them (`github.com/legalize-dev`).
- Version: the date the corpus was cut, written here by whoever fills the library.
- Licence: the corpus's own terms, written here before any quote leaves the folder.
- Coverage: the Basic Law and the Civil Code to start; add a file per law.

Files: `basic-law.md`, `civil-code.md`.
