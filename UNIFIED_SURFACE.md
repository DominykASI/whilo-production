# Unified Surface (Architecture A reference)

This folder contains a preserved copy/reference of `whilo-swas-main` to support a future **Architecture A**: one Electron shell capable of loading the current Pets experience and/or a unified Dots/Pets surface.

- Location: `unified-surface/whilo-swas-main/`
- Source archived from the pre-production workspace layout into this production bundle for integration/reference.
- Current Pets desktop flow remains based on the core app (`electron/`, `src/`, `server/`, scripts in `package.json`). Do not assume this reference is wired into the default runtime unless explicitly integrated.

See `unified-surface/whilo-swas-main/README.md` and `docs/` inside that folder for the original monorepo context (web, desktop shell, shared agent core).
